# Nexus Terminal HTML prototipi

`index.html` dosyasını tarayıcıda açın. Kurulum, API veya sunucu gerekmez. Sol menü yedi mevcut ana ekran arasında geçiş yapar; düğmeler modal ve görünüm durumlarını gösterir.

Bu klasör yalnızca tasarım incelemesi içindir. Fiyat, portföy, haber, araştırma ve işlem verisi üretmez veya kaydetmez. Gerçek uygulama `frontend/src` altında kalır.

| Prototip | Uygulama rotası | Stitch kaynağı |
| --- | --- | --- |
| Genel Bakış | `/dashboard` | Portfolio Overview; Nexus Terminal Flow |
| Grafik Çalışma Alanı | `/workspace` | Chart Workspace |
| Portföy | `/portfolio` | Portfolio Overview; Portfolio Ledger & Transactions |
| İzleme Listesi | `/watchlist` | Modernized Watchlist Workspace |
| Haber Merkezi | `/news` | News Center |
| Sembol Araştırması | `/reports` | Mevcut ürün bileşeni; doğrudan Stitch ekranı yok |
| İşlem Günlüğü | `/journal` | Trading Journal; Log New Trade Modal |

Stitch projesi: `projects/5675941308316268758` (Nexus Terminal, koyu tema). Renk ve yerleşim projenin tasarım sisteminden; eksik ekranların yapısı mevcut React bileşenlerinden alınmıştır. HTML prototip, Stitch ekranlarının birebir kopyası olarak değerlendirilmemelidir.
